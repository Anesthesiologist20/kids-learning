سكينة، بطلة الـ Full Mark! ⭐

تدريب سريع بدون صور، وبأمثلة كثيرة. افهمي القاعدة، تدربي، وراجعي أخطاءك حتى تتقنيها.

القاعدة في دقيقة

Comparative — مقارنة بين اثنين

صفة قصيرة + er + than
أو more + صفة طويلة + than

Ali is taller than Omar.
Math is more difficult than Art.
Superlative — واحد هو الأعلى بين مجموعة

the + صفة قصيرة + est
أو the most + صفة طويلة

Ali is the tallest boy.
This is the most interesting book.

تذكري: than غالبًا مقارنة، و the مع مجموعة غالبًا تفضيل. لا تعتمدي على الكلمة وحدها؛ افهمي معنى الجملة.

أهم التحويلات والأخطاء

tall → taller → tallest
fast → faster → fastest
smart → smarter → smartest
clean → cleaner → cleanest
small → smaller → smallest
big → bigger → biggest
hot → hotter → hottest
easy → easier → easiest
happy → happier → happiest
nice → nicer → nicest
good → better → best
bad → worse → worst
far → farther/further → farthest/furthest
expensive → more expensive → most expensive
interesting → more interesting → most interesting
beautiful → more beautiful → most beautiful

انتبهي: more cheaper ❌ والصحيح cheaper ✅، و goodest ❌ والصحيح best ✅.
