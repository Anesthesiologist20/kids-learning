اختاري طريقة المذاكرة

لأفضل نتيجة: اقرئي القواعد، حلي ورقة المدرسة، ثم تحدي السرعة. كل إجابة تظهر معها القاعدة التي تفسرها.

خطة مذاكرة سريعة: 5 دقائق للقواعد، ثم ورقة المدرسة (13/13 هدفنا)، ثم جولتان من تحدي السرعة، ثم راجعي أي أخطاء باقية.

الشرح السريع: شيئين أم مجموعة كاملة؟

Comparative — المقارنة بين اثنين

عندما نقارن شخصين أو شيئين، نستخدم غالبًا than.

Ali is taller than Omar.
A car is more expensive than a bike.

Superlative — الأفضل أو الأكثر بين مجموعة

عندما نقارن واحدًا بكل المجموعة، نستخدم غالبًا the قبل الصفة العليا.

Ali is the tallest in class.
This is the most expensive bag.

الصفات القصيرة

نضيف غالبًا -er للمقارنة و-est للتفضيل.

tall → taller → tallest
fast → faster → fastest
small → smaller → smallest

الصفات الطويلة

لا نضيف -er مع more، ولا -est مع most.

expensive → more expensive → most expensive
interesting → more interesting → most interesting

إذا انتهت الصفة بـ y

نحوّل y إلى i إذا سبقها حرف ساكن.

easy → easier → easiest
happy → happier → happiest

التضعيف ونهاية e

نكرر الحرف الأخير أحيانًا، وإذا انتهت الصفة بـ e نضيف r أو st.

big → bigger → biggest
hot → hotter → hottest
nice → nicer → nicest

احفظي هذه الثلاثة

هذه صيغ شاذة يجب حفظها.

good → better → best
bad → worse → worst
far → farther / further → farthest / furthest

أخطاء شائعة جدًا

انتبهي لهذه الأخطاء في المسابقة.

✗ more taller → ✓ taller
✗ the goodest → ✓ the best
✗ more cheaper → ✓ cheaper
✗ the most fastest → ✓ the fastest

جدول كامل للحفظ والمقارنة

انتبهي: التفضيل في الجملة يحتاج عادةً the قبل الصيغة المكتوبة بالجدول.

AdjectiveComparative + thanthe + Superlative

ملخص سكينة في دقيقة واحدة

than → comparative | the → superlative (في نمط أسئلة الورقة).

صفات قصيرة

tall → taller → tallest
fast → faster → fastest
smart → smarter → smartest

صفات طويلة

expensive → more expensive → most expensive
interesting → more interesting → most interesting

تغيّر التهجئة

easy → easier → easiest
big → bigger → biggest
hot → hotter → hottest

احفظي الشاذ

good → better → best
bad → worse → worst
far → farther/further → farthest/furthest
انتبهي: لا تقولي more faster أو the goodest. الصواب: faster و the best.
